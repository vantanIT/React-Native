
# Bài tập 1: Thiết kế giao diện React Native

## 1. Thông tin bài tập
- Tên ứng dụng: MyApp_V2
- Chủ đề: Study Planner
- Công cụ: React Native, Expo Snack

## 2. Link ứng dụng Expo
Dán link Expo Snack của ứng dụng tại đây.

## 3. Nội dung thực hiện
- Xây dựng giao diện Study Planner.
- Tách giao diện thành các component: Header, Schedule, Goals và Footer.
- Sử dụng StyleSheet.create để định nghĩa kiểu giao diện.
- Áp dụng màu nền, kích thước chữ, khoảng cách và đường viền cho các component.

## 4. Hình ảnh minh chứng
Thêm ảnh giao diện ứng dụng sau khi hoàn thành.
