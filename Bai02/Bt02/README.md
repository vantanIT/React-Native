
# Bài tập 2: Thiết kế trang chủ ứng dụng học tập

## 1. Thông tin bài tập
- Tên ứng dụng: Study Planner
- Công cụ: React Native, Expo Snack

## 2. Link ứng dụng Expo
https://snack.expo.dev/@vanit3010/myapp_v1

## 3. Các component
- Header: Hiển thị lời chào và thông tin sinh viên.
- StatCard: Hiển thị thống kê khóa học.
- CourseCard: Hiển thị thông tin môn học và tiến độ.
- BottomMenu: Thanh menu ở cuối màn hình.

## 4. Công nghệ sử dụng
React Native, JavaScript, StyleSheet.
