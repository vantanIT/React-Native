
# Bài tập 4: Xây dựng ứng dụng nhiều màn hình

## 1. Thông tin
- Tên ứng dụng: MultiScreenApp
- Công nghệ: React Native, Expo
- Điều hướng: React Navigation Stack

## 2. Chức năng
- HomeScreen: Màn hình trang chủ.
- ListScreen: Hiển thị danh sách sách.
- DetailScreen: Hiển thị thông tin chi tiết sách.
- Chọn sách trong danh sách để xem chi tiết.
- Có nút quay lại màn hình trước.

## 3. Cấu trúc chương trình
- App.js: Khai báo dữ liệu, giao diện và cấu hình Stack Navigation.

## 5. Hình ảnh minh chứng
