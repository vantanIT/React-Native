
# Bài tập 5: Thiết kế giao diện có hiệu ứng động

## 1. Thông tin
- Tên ứng dụng: AnimateApp
- Công nghệ: React Native, Expo
- Hiệu ứng: Animated API

## 2. Chức năng
- Theo dõi tiến độ mục tiêu học tập.
- Nút bắt đầu và cập nhật tiến độ.
- Hiển thị thông báo khi hoàn thành.
- Hiệu ứng phóng to thông báo hoàn thành.

## 3. Các component
- ProgressCard: Hiển thị mục tiêu và tiến độ.
- ActionButton: Nút thao tác.
- AnimatedMessage: Thông báo có hiệu ứng động.
