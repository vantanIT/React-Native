
# Bài tập 3 - Ứng dụng BookStore

## 1. Giới thiệu
Xây dựng ứng dụng bán sách bằng React Native và Expo.

## 2. Chức năng
- Hiển thị danh sách 6 cuốn sách.
- Hiển thị tên sách, tác giả, hình ảnh, giá bán và mô tả.
- Sử dụng component ProductCard để tái sử dụng giao diện.
- Truyền dữ liệu sách vào ProductCard thông qua props.
- Hiển thị danh sách bằng phương thức map().

## 3. Công nghệ sử dụng
- React Native
- JavaScript
- Expo Snack

## 4. Danh sách sách
1. Nhân Gian Thất Cách - Dazai Osamu
2. Tà Dương - Dazai Osamu
3. Tội Ác và Hình Phạt - Fyodor Dostoevsky
4. Chiến Tranh và Hòa Bình - Leo Tolstoy
5. Những Người Khốn Khổ - Victor Hugo
6. Nhà Thờ Đức Bà Paris - Victor Hugo

## 5. Cấu trúc mã nguồn
- App.js: Màn hình chính và danh sách sách.
- ProductCard.js: Component hiển thị thông tin từng cuốn sách.
